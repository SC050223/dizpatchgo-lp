AI-powered driver assignment AI驱动的司机指派

Stop guessing which driver to send. DizpatchGO uses Google Maps Distance Matrix API and a scoring algorithm to rank available drivers by real driving time, language compatibility, and vehicle capacity. 不再猜测该派哪位司机。DizpatchGO 使用谷歌地图距离矩阵API和评分算法，按实际驾驶时间、语言兼容性和车辆容量对可用司机进行排名。

  • ✓
    Ranks top 5 nearest drivers by real driving time — not straight-line distance 按实际驾驶时间（非直线距离）排列最近的5位司机
  • ✓
    Language match indicator — ensure driver speaks client's language 语言匹配指标——确保司机会说客户的语言
  • ✓
    Capacity check — only suggest vehicles that fit the requested seats 容量检查——仅推荐满足所需座位数的车辆
  • ✓
    Conflict detection — checks for overlapping scheduled trips 冲突检测——检查排期行程是否有重叠
  • ✓
    50km radius filter to reduce irrelevant API calls and costs 50公里半径过滤，减少不必要的API调用和成本

Order Management订单管理

Complete order lifecycle control 完整的订单生命周期控制

Every order flows through a transparent, auditable pipeline. Admins have full control at every stage — from scheduling to cancellation with documented reasons. 每个订单都通过透明、可审计的流程处理。管理员在每个阶段都拥有完全控制权——从排期到取消（附记录原因）。

  • ✓
    5 order stages: Pending → Assigned → Ongoing → Completed / Cancelled 5个订单阶段：待处理→已分配→进行中→完成/取消
  • ✓
    Support for Point-to-Point, Hourly, and Charter transport types 支持点对点、按小时和包车运输类型
  • ✓
    Schedule future orders with auto-transition when pickup time arrives 排期未来订单，到取车时间时自动过渡
  • ✓
    Reassign or unassign orders mid-trip with a full transfer audit trail 行程中途重新分配或取消分配，附完整的转让审计记录
  • ✓
    Add-on charges with documented reason for billing transparency 附加收费并记录原因，确保计费透明
Fleet Compliance车队合规

Never miss a compliance deadline 绝不错过合规截止日期

DizpatchGO monitors the compliance status of every vehicle in your fleet — road tax, insurance, Puspakom inspection, and service mileage — and flags issues 30 days in advance. DizpatchGO 监控车队中每辆车的合规状态——道路税、保险、车检和服务里程——并提前30天标记问题。

  • ✓
    Road tax, insurance & Puspakom expiry tracking per vehicle 每辆车的道路税、保险和车检到期追踪
  • ✓
    Colour-coded status: Valid (green) / Expiring Soon (amber) / Expired (red) 彩色状态：有效（绿色）/即将到期（琥珀色）/已到期（红色）
  • ✓
    Service mileage tracking — alerts when service is due or overdue 服务里程追踪——服务到期或逾期时发出警报
  • ✓
    Traffic summons management — track offense type, amount, and status 交通传票管理——追踪违规类型、金额和状态
  • ✓
    Maintenance log — full service history with costs and receipts 维护日志——包含费用和收据的完整服务历史

Driver & Access Management司机与访问管理

Secure, role-based access control 安全的基于角色的访问控制

Manage every driver's profile, languages, and credentials from one admin panel. A three-tier role system ensures the right people have the right access. 从一个管理面板管理每位司机的资料、语言和凭证。三层角色系统确保正确的人拥有正确的访问权限。

  • ✓
    Full driver CRUD — add, edit, delete from the admin panel 完整的司机CRUD——从管理面板添加、编辑、删除
  • ✓
    Three roles: Driver, Admin, and SuperAdmin with scoped permissions 三种角色：司机、管理员和超级管理员，各有权限范围
  • ✓
    bcrypt password hashing — passwords never stored in plain text bcrypt密码哈希——密码从不以明文存储
  • ✓
    Forced password reset on first login for all new accounts 所有新账户首次登录时强制重置密码
  • ✓
    Session-based authentication stored securely in PostgreSQL 基于会话的身份验证，安全存储在PostgreSQL中
