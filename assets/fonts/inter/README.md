# Inter

Self-hosted, unmodified Inter v20 Latin variable font from Google Fonts.

- Source: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Font declarations: https://fonts.googleapis.com/css2?family=Inter:wght@400..900&display=swap
- Retrieved: 29 October 2026
- License: SIL Open Font License 1.1; see OFL.txt (from https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt).

This is the same Latin font file returned by the site's previous Google Fonts request. The CSS exposes weights 400–900, which are used on the six HTML pages. Weight 300 was requested previously but is unused. The unicode range matches Google's Latin subset; Chinese characters and symbols outside this range retain the existing system-font fallback.

Each page preloads this font with `crossorigin` so the preload is reused by CSS. Keep the preload URL and the `@font-face` URL in sync when updating the font. Use a new versioned filename for a font update and retain its license.
